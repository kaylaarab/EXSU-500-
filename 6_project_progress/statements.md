## Use of Generative AI statement (draft)
Generative AI was used in this project as follows, and all of it was directed and reviewed by team members, who are responsible for everything submitted.

- **Tool:** Claude Code (Anthropic), an AI coding assistant, used in a cloud session on behalf of Siham Khaldoun.
- **Code:** drafting and debugging the data preprocessing, model training, evaluation, ablation, calibration, subgroup-audit and interface scripts (`scripts/`, `7_interface/`). Results were produced by running that code on the public dataset; no result was written by the assistant without being computed.
- **Analysis and documentation:** drafting the dataset analysis, decision log, benchmarking report, model card and progress notes from computed results and from papers that were retrieved and read by the assistant.
- **Literature:** the assistant searched PubMed and the web, retrieved open-access papers, and wrote abstract-based summaries. **These summaries are screening aids, not evidence that anyone read the papers.** Every reference cited in the report must be read and verified by a team member; the assistant's earlier notes contained attribution errors that were corrected after reading the primary sources (see `6_project_progress/progress_log.md`).
